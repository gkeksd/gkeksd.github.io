## 라이브러리 함수
c++에는 미리 정의되어 호출해 사용할 수 있는 함수가 여러 라이브러리들에 있다. 이러한 함수들을 사용하기 위해선 미리 그 함수가 들어있는 라이브러리를 include 해주어야 한다. 대표적인 라이브러리로는 수학 관련 함수들이 있는 cmath 라이브러리와 시간과 관련된 함수들이 있는 ctime 라이브러리 등이 있다.

이러한 함수들을 코드 내에서 사용할 때에는 함수명(매개변수);식으로 호출하며, 이 호출에 따라 미리 정의된 함수 구문이 실행되어 특정한 값을 반환하거나 코드를 실행한다. 이때 함수 호출에 넣는 매개변수를 input, 함수 실행의 결과로 반환되는 값을 output으로 보면, 함수란 곧 input이 특정한 코드를 거쳐 output으로 반환되는 구조임을 알 수 있다. 다만, 이때 input은 반드시 있어야 하는 것은 아니며, output 역시 반드시 return의 형태로 반환될 필요는 없다.

![화면 캡처 2024-07-02 175932](https://github.com/gkeksd/codding-archive/assets/54362230/ad62a3bd-e2d9-4e55-81d4-ee288f933d78)
이 사진은 cmath 라이브러리에서 사용할 수 있는 여러 함수들을 나열한 것이다. 이 함수들을 활용해 짠 전형적인 예제 코드는 다음과 같다.
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << "abs(8) = " << abs(8) << endl;
    cout << "abs(-8) = " << abs(-8) << endl;

    cout << "floor(12.78) = " << floor(12.78) << endl;
    cout << "ceil(12.78) = " << ceil(12.78) << endl;

    cout << "log(100) = " << log(100) << endl;
    cout << "log10(100) = " << log10(100) << endl;

    cout << "exp(5) = " << exp(5) << endl;
    cout << "pow(2, 3) = " << pow(2, 3) << endl;

    cout << "sqrt(100) = " << sqrt(100) << endl;
}
```
예를 들어 abs(8)의 경우 abs 함수를 라이브러리에서 호출해 실행하는데, 이때 8을 매개변수로서 input으로 투입해 이의 절대값 8을 output으로 리턴한다.

cmath 라이브러리를 이용해 다음 코드와 같이 삼각함수도 계산할 수 있다.
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    const double PI = 3.141592653589793238462;
    int n;
    double s, peri, area;

    do {
        cout << "변의 개수를 입력하세요(4 이상의 정수): ";
        cin >> n;
    } while (n < 4);

    do {
        cout << "변의 길이를 입력하세요: ";
        cin >> s;
    } while (s <= 0.0);

    peri = n * s;
    area = (n * pow(s, 2)) / (4 * tan(PI / n));

    cout << "둘레: " << peri << endl;
    cout << "넓이: " << area;
}
```
위 코드에서 tan함수를 통해 매개변수의 탄젠트 값을 계산해 반환하였다.

ctime 라이브러리에 있는 함수들 중 time 함수는 time(0)의 형태로 호출하며, 1970년 1월 1일부터 현재 시간까지의 기간을 초 단위로 계산한 유닉스 타임(UNIX time)을 반환한다.

### (Pseudo) 난수
난수(Random number)란 무작위로 생성된 숫자를 뜻하는데, 컴퓨터 환경에서 완전한 난수를 구현하기는 불가능하고 난수에 가깝게 구현할 수 있기에 엄밀하게는 유사(Pseudo)-난수이다.

컴퓨터에서 난수값을 생성할 때는 난수표라는 것을 만들어 난수들을 나열한 후, seed 값이라는 난수를 생성하기 시작할 시작점을 지정해 그 seed 값을 생성한 후 난수를 호출하면 그 seed 값부터 난수표에 적힌 숫자들이 생성된다. 이 seed 값은 c++에서 srand(seed)를 통해 생성할 수 있으며, 본격적인 난수 생성은 rand() 함수를 통해 한다.

만약 난수에 범위를 지정하고 싶을 경우, rand() % (b-a+1) 형식으로 코드를 작성하여 a 부터 b까지, b-a+1개 숫자 중에서 난수를 생성하도록 할 수 있다. 여기에 추가로 값을 더하거나 뺌으로서 난수가 생성되는 범위 자체도 이동시킬 수 있다. 한편, 유닉스 타임을 반환하는 time 함수를 seed 값으로 지정할 경우 수들을 난수를 생성할때마다 다른 수로, 코드 내에서 난수를 여러번 생성할 경우, 생성함으로서 가장 무작위 난수에 가깝게 구현할 수 있다.

다음은 난수를 사용한 전형적인 프로그램 예제이다.
```cpp
#include <iostream>
#include <iomanip>
#include <cstdlib>
using namespace std;

int main() {
    unsigned int seed{ 0 };

    cout << "Enter seed: ";
    cin >> seed;
    srand(seed); //seed 생성

    for (int counter{ 1 }; counter <= 10; ++counter) {
        cout << setw(10) << (1 + rand() % 6);
        if (counter % 5 == 0) cout << endl;
    }
}
```

## 함수(function)
함수란 하나의 특정한 작업을 수행하기 위해 설계된 코드 집합이다. 함수는 함수를 감싼 하나의 헤더(header)와 중괄호로 감싸진 문장(body)로 이루어진다.

프로그램 내에서 함수를 호출하면, 프로그램의 실행 흐름이 그 호출된 함수 내부로 이동한다. 함수가 모두 실행되어 종료되면, 프로그램의 진행 흐름이 함수를 호출한 위치로 되돌아가 그 다음 코드가 실행된다.

일반적으로 함수는 다음과 같은 형태로 정의된다.
```cpp
리턴_자료형 함수 이름(매개변수 리스트) {
    본문
}
```

한편 함수가 호출되는 코드 이후에 정의되어 컴파일러가 해당 코드를 제대로 해석할 수 없을 때, 이 문제를 방지하기 위해 main 함수 외부에 함수의 Prototype을 미리 선언해 둔 것을 함수 선언(Function prototype)이라고 한다. 위의 함수 정의 중 첫 부분만을 사용하며, 함수가 이러한 형태라는 것을 컴파일러에게 미리 알려주는 역할을 한다. 이때 매개변수의 이름은 생략하고 자료형만 표기해도 된다.

함수 호출이란 어떠한 정의된 함수를 실행하도록 하기 위한 구문이다. 일반적으로 함수 이름(매개변수 목록)의 형태로 호출되며, 다른 구문의 일부로 사용하거나 호출한 함수의 반환값을 변수에 할당하는 식으로 사용도 가능하다.

### 매개변수와 인자
매개변수란 함수 정의에서 선언되는 변수로, 함수 내에서 실제로 만들어져 함수 호출로 인자를 건네받아 코드를 실행한 후 함수가 종료되면 사라진다.

인자란 함수 호출 과정에서 넣어주는 입력(input) 값으로, 이 인자가 매개변수에 전달됨으로서 매개변수를 초기화하는 역할을 한다.

각각의 변수는 함수 내에서 선언되어 사용되고 함수 외에서 사용할 수는 없다. 각각의 함수 실행에 외부 변수가 필요한 경우 매개변수와 인자를 사용하므로, **실제로 매개변수와 인자의 관계는 변수의 선언과 초기화로 이해하는 것이 적절하다.**

### 함수의 장점
1. 분할 처리: 복잡하고 어려운 일을 한번에 하는 것보다 작은 일을 여러번 하는 것이 운영체제의 작업 처리 방식상 더 효율적이다. 
2. 디버깅: 프로그램에 오류가 났을 때 디버깅을 용이하게 하기 위해 코드를 작은 함수들로 나누어 중단점을 설정해 분석함으로서 각각의 함수 단위로 오류를 쉽게 찾을 수 있다.
3. 코드 재사용: 같은 작업을 하는 코드가 여러 번 사용될 필요가 있을 때 함수를 사용하면 작업의 효율성과 코드의 길이를 모두 개선할 수 있다.

### 함수의 종류
c++의 함수는 총 네 종류가 있다.

1. 매개변수와 반환값이 모두 없는 void 함수: 매개변수가 없으므로 함수 내부에서 필요한 작업을 모두 완결시켜야 하며, 반환값이 없으므로 값을 넣어야 하는 위치에 함수를 활용할 수 없다.
2. 매개변수는 없지만 반환값은 있는 void 함수: 기능을 함수 내부에서 모두 처리한 후 나온 결과를 반환한다. 코드의 입력-처리-출력 부분 중 입력 부분에 주로 사용한다. 
3. 매개변수는 있지만 반환값은 없는 함수: 매개변수로 외부 입력값을 받아 기능을 수행한 후 출력한다. 입력-처리-출력 중 출력 부분에 주로 사용한다.
4. 매개변수와 반환값 모두 있는 함수: 외부에서 매개변수로 입력값을 받아 기능을 수행한 후 그 결과를 리턴한다.

## 참조자 타입(reference type)
변수를 선언할 때, 자료형 뒤에 &기호를 붙임으로서 참조자 타입임을 명시한다. 변수를 참조자 타입 변수에 할당함으로서 **피할당 변수의 새로운 이름을 만들어낸다** 참조 시 값만이 복사되고 주소는 복사되지 않는 C언어와 달리, c++의 참조자 타입은 값과 주소 모두를 복사한다. 이로서 이론상으로 존재하던 call by reference를 실제로 구현할 수 있다.

### 값에 의한 전달(pass by value)
![화면 캡처 2024-07-02 202224](https://github.com/gkeksd/codding-archive/assets/54362230/c0f479d5-955d-4b15-a73b-f9fdd594147f)
함수 간 매개변수를 통해 인자를 전달할 때, 인자의 값만을 복사하고 주소는 복사하지 않은 상태로 전달하는 방법이다. 주소를 복사하지 않기에 함수에서 매개변수의 값을 바꾼 상태로 반환하더라도 원래 변수의 값은 변경되지 않는다. 

### 참조에 의한 전달(pass by reference)
![화면 캡처 2024-07-02 202310](https://github.com/gkeksd/codding-archive/assets/54362230/41e18123-808b-4776-b283-f2df8eda426e)
매개변수를 통해 다른 함수로 인자를 전달할 때, 참조자 타입을 사용하여 해당 인자의 새로운 이름을 매개변수로 생성하는 방법이다. 따라서 함수 내에서 매개변수의 값을 바꾼 상태로 반환하면 원래 변수의 값도 변경된다.
