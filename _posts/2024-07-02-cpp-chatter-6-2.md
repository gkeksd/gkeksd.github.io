## 리턴(return)
함수가 실행된 후 특정한 결과를 함수의 호출 위치로 전달하는 것을 리턴이라고 한다. 함수의 타입이 void인 함수는 리턴이 없으며, 이외 함수의 타입이 무엇이냐에 따라 리턴할 값의 자료형도 달라진다. 

일반적으로 리턴은 pass by value 방식으로 진행된다. pass by reference 방식도 가능은 하나, 주의가 필요하다. 예를 들어, 다음과 같은 방식으로 참조자 타입을 리턴할 수 있다.
```cpp
#include <iostream>
using namespace std;

// 함수 내 지역변수를 참조자 타입으로 리턴하지 마시오.
int& sum(int num1, int num2) {
    int sum = num1 + num2;
    return sum;
}

int main() {
    int& a = sum(5, 16); // 14
    int& b = sum(2, 12); // 14
    cout << a << endl;
    cout << b << endl;
    cout << a + b << endl;
}
```
이 코드에서 sum 함수를 호출해 참조자 타입 변수에 할당하였고, 마찬가지로 함수에서도 반환 자료형에 참조자 타입을 붙임으로서 리턴 값을 참조자 타입 방식으로 반환하였다.

그러나, 참조자 타입으로 값을 리턴할 경우, 함수 내의 지역변수를 리턴해서는 안된다. 예를 들어, 위의 코드에서 a의 값은 프로그래머가 21을 의도하고 넣은 것이지만, sum 함수의 종료와 동시에 21을 넣어 반환한 sum 변수가 사라지기에 a 변수 또한 참조자 타입의 성질에 의해 같이 사라진다. 그러나 하드디스크의 원리에 따라 메모리는 사라졌지만 값은 남은 상태이기에 읽고 쓸 수는 있는 상태인데, 여기서 b 변수에 새롭게 함수를 다시 호출해 참조자 타입으로 할당했으므로 선입후출이라는 스택(stack)의 구조에 따라 21이라는 값에 14라는 메모리 값이 덮어씌워진다. 따라서 a와 b 모두 14가 출력되게 된다. 

다만, 모든 경우에 이렇게 동작하지는 않는다. 허나 애초에 지역변수를 참조자 타입으로 리턴해서는 안되기에 그것에 대한 것은 신경쓰지 않아도 된다.

## 기본 매개변수(Default Parameter)
함수 호출시 매개변수에 전달된 인자값이 없을 때, 함수 정의시나 함수 프로토타입 정의시에 매개변수에 초기값까지 같이 정의했을 때 이를 기본 매개변수라고 한다. 만약 매개변수 중 일부에만 기본값을 적용하고자 한다면, 매개변수 목록 오른쪽부터 기본값을 적용해야만 한다.

앞에서 보았듯 기본 매개변수는 프로토타입이나 함수 정의시 중 하나에만 정의할 수 있는데, 보통 함수 프로토타입을 사용할 경우 여기에 사용한다.

매개변수에 기본값이 적용된 함수를 호출할 때 새로운 값을 매개변수에 인자로 전달한다면, 그 인자 값이 기본값을 덮어씌운다. 

이 인자는 모든 매개변수에 대해 적용할 필요는 없으며 왼쪽부터 순차적으로 적용되자만, 만약 일부 매개변수에만 기본값이 적용되었을 때 일부 매개변수에만 값이 할당되도록 인자값을 전달한다면 에러가 발생한다. 즉 다음과 같은 상황에서 에러가 발생한다.
```cpp
void print(int a, in b, int c = 1); //함수 프로토타입 정의

int main() {
    . . .
    print(5); //error
    . . .
}
```
이 경우에 매개변수 중 c에만 1이라는 기본값이 설정되어 있고, 인자값이 5 하나만 전달되므로 a에 5가 할당된다. 이때 b만 값을 가지지 못했으므로 에러가 발생한다.

일부 적용된 기본값은 유지하면서 기본값이 없는 매개변수에만 인자를 전달하고 싶다면, 기본값이 적용된 매개변수의 인자자리에 0을 쓰면 된다.

## 함수 오버로딩(function overloading)
### 함수 시그니처(funcion signiture)
함수 시그니처란 컴파일러가 서로 다른 두 함수를 구분하는 기준이다. 컴파일러는 함수의 이름과 매개변수의 타입, 개수, 순서에 따라 함수를 구분하며, 이것이 일치하지 않는다면 이름이 같더라도 서로 다른 함수로 취급된다. 이때 return 타입은 시그니처에 포함되지 않는다.
### 함수 중복정의
함수 중복정의, 또는 함수 오버로딩이란 위의 함수 시그니처를 기반으로 같은 이름의 함수를 서로 다르게 정의하는 기법이다.이때 함수 이름은 같지만 매개변수는 다르게 하여 컴파일러가 서로 다른 함수로 구분하게 한다. 따라서 시그니처가 다르기에 이론상 같은 이름의 함수를 무한정 정의할 수 있다.

그런데, 함수를 중복정의한 후 각각의 함수를 호출할 때, **모호한 상황**이 발생할 수 있다. 모호한 상황이란, 각각의 함수를 호출할 때 전달한 매개변수의 인자가 중복정의된 각 함수에 모두 들어갈 수 있어 컴파일러가 어떠한 함수에 인자를 전달해야 할지 판단하지 못하는 경우를 이른다. 이때 컴파일러는 이 상황을 에러로 판단한다. 즉 다음의 예제가 그 경우이다.
```cpp
// 각각 함수 프로토타입 정의
double add(int a, double b);

double add(double a, int b);

int main() {
    cout << add(1, 2); // error
    cout << add(1.5, 2.5); // error
}
```
이 경우에 첫번째 add 함수에는 int 형 a에 1이 들어갈 수 있고 double 형 b 역시 double 형이 int 형보다 상위의 자료형이므로 int 형 2가 들어갈 수 있다. 두 번째 add 함수도 마찬가지로 두 인자 모두 들어갈 수 있으므로, 모호한 상황에 해당한다.

반면 두 번째 add 함수 호출의 경우, int 형이 double 형보다 하위의 자료형이므로 double 형 값이 들어갈 수 없다. 따라서 어느 함수에도 인자가 완전히 전달되지 못해 에러가 발생한다.

이는 인자를 전달하지 않는 경우도 마찬가지이다. 다음의 경우처럼 매개변수의 기본값은 설정된 함수와 매개변수가 없는 중복정의된 함수가 있을 때, 그 이름의 함수를 매개변수 인자 없이 호출한다면 두 함수 모두에 할당될 수 있기에 모호한 상황에 해당한다.
```cpp
#include <iostream>
using namespace std;

void print() {
    cout << "function" << endl;
}

void print(int a = 0) {
    cout << a << endl;
}

int main() {
    print(5);
    print();
}

```
첫 번째 print 함수 호출의 경우, 인자 5가 기본값이 정의된 변수 a에 덮어씌워 두 번째 print 함수를 호출한다. 반면 두 번째 print 함수 호출의 경우, 아무런 인자를 전달하지 않는데 애초에 매개변수가 없는 첫번째 함수와 기본값이 이미 정의된 두 번째 함수 모두에 전달될 수 있으므로 모호한 상황이다.

## 스코프(Scope)
스코프란 상수, 변수, 함수 등 객체 식별자에 접근할 수 있는 범위를 말한다.
### 지역 스코프
![화면 캡처 2024-07-04 175718](https://github.com/gkeksd/codding-archive/assets/54362230/064fb340-5aa0-4657-b9a6-5664f74c7c19)
블록 스코프라고도 부른다. 스코프 범위에 해당하는 객체의 전 영역이 이에 해당한다. 즉 다음과 같은 for문에서
```cpp
for (int i = 0; i < 5; i++) {
    . . .
}
```
i 변수의 스코프는 해당 변수가 선언된 for 문의 전체 영역이다. 또한 어떠한 함수의 지역변수의 스코프는 그 함수 전체 영역에 해당한다.

전역 스코프란 함수 등 객체 외부의 영역에서 선언되어 선언된 위치부터 전 영역에서 사용할 수 있는 범위를 말한다.

함수의 경우 함수 이름의 스코프는 함수가 선언된 영역부터 코드가 끝날 때까지의 전 영역이며, 프로토타입이 선언되었을 경우 프로토타입이 선언된 위치를 기준으로 한다. 

함수의 매개변수의 경우 지역변수에 해당하기에 그 매개변수가 선언된 함수 영역만을 스코프 범위로 한다.

## 변수
### 지역변수와 전역변수
지역변수란 위에서 보았듯 함수 내에서 선언되어 그 선언된 함수 내에서만 사용할 수 있는 변수를 뜻한다. 지역변수의 스코프는 함수가 선언된 위치부터 그 함수가 끝날때까지이다. 함수가 종료되면 지역변수도 자동으로 소멸한다.

전역변수란 함수 외부에서 선언되어 코드 전 영역에서 사용될 수 있는 변수를 뜻한다. 전역변수의 스코프는 **프로그램의 전 영역**에 해당하며, **프로그램이 시작할 때 생성되어 끝날 때 소멸한다.** 

### 정적 지역변수
정적 지역변수란 함수 내에서 생성되어 선언된 함수 내에서만 스코프를 가진다는 것은 지역변수와 같지만, 지역변수와 달리 프로그램이 시작될때부터 끝날 때까지 항상 접근 가능한 변수를 말한다. 이 변수의 초기화 문장은 한번만 실행되며, 반복문이 실행된 경우 두번째부터는 무시한다.

### 섀도잉(Shadowing), 범위 지정 연산자(:: )
섀도잉이란 함수 내에서 지역 수준 객체를 선언할 때 중괄호로만 감싸고 객체의 이름 등은 생략하는 것을 뜻한다. 예를 들어 다음의 경우가 있을 수 있다.
```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 5;
    cout << sum << endl;

    {
        int sum = 3;
        cout << sum << endl;
    }

    cout << sum << endl;
}
```
다음의 코드에서 안쪽 중괄호로 묶인 문장은 하나의 지역 스코프를 형성한다. 따라서 괄호 안의 sum 변수와 괄호 밖의 main 함수의 sum 변수는 별개이다. 그 결과, 첫번째와 세 번째 sum 출력에서는 main 함수의 변수 값인 5가 출력되지만, 중괄호 안의 두번째 sum 출력문에서는 3이 출력된다.

한편 범위 지정 연산자란, 변수를 가장 가까운 지역 수준의 변수가 아닌 동일한 이름의 전역 변수에 접근할 수 있게 해주는 연산자를 말한다. 예를 들어 다음의 코드에서,
```cpp
#include <iosteam>
using namespace std;

int num = 5;

int main() {
    int num = 25;
    cout << "전역변수 num의 값: " << ::num << endl;
    cout << "지역변수 num의 값: " << num << endl;
}
```
범위지정 연산자 ::를 붙인 num은 가장 가까운 지역변수 num이 아닌, 5의 값을 가진 전역변수 num의 값을 출력한다. 한편 두 번째 일반적인 num의 경우 규칙대로 가장 가까운 지역변수 num의 값을 호출한다.

## 인라인 함수&상수 매개변수
인라인 함수(Inline function)란, 일반적인 함수의 호출과정을 거치지 않고 함수의 모든 코드를 호출한 그 자리에 바로 삽입해 사용하는 것을 의미한다. 즉 다음과 같은 코드에서,
```cpp
#include <iostream>
using namespace std;

inline double cube(const double& side) {
    side = 7.5;   // error
    return side * side * side;
}

int main() {
    double sideValue = 5.5;
    cout << "Volume of cube with side " 
         << sideValue << " is " << cube(sideValue) << endl;

    cout << "Volume of cube with side "
         << 3.5 << " is " << cube(3.5) << endl;

    return 0;
}
```
함수를 호출하는 cube(매개변수) 자리에 return 값인 side * side * side를 바로 삽입해 그대로 사용할 수 있게 해준다. 이는 함수가 호출되면 그 함수로 이동해 코드를 실행한 뒤 함수가 끝나면 다시 호출된 그 자리로 돌아와 다음 코드를 실행하는 일반적인 함수 호출 방식보다 훨씬 간결하고 빠르게 사용할 수 있다.

한편 위의 코드에서, cube 함수의 매개변수인 side가 상수(const)로 선언되어 있는데, 이는 함수의 매개변수에 Lvalue가 아닌 Rvalue가 인자로 전달될 때 Rvalue 값이 수정되지 않도록 하기 위한 것으로 이를 상수 매개변수(const parameter)라고 한다.

## 재귀함수(Recursion function)
재귀함수란 함수 내에서 자기자신을 다시 호출하는 함수를 말한다. 실행하고 있는 자신의 함수를 호출해 실행한 후 값을 반환하기에, 재귀를 하기 위해서는 재귀를 통해 문제의 크기를 줄여 같은 방식으로 재정의할 수 있어야 한다. 즉 한개의 문제를 재귀를 통해 분할해서 풀 수 있어야 한다는 뜻이다.

또한, 재귀를 반복해 나가다 더이상 재귀를 하지 못하는, 즉 더이상 문제를 분할하지 못하는 지점이 있어야 하며 그 지점에서부터 계산을 시작해 재귀를 호출한 역순으로 진행하여 최종적으로 값을 반환한다.

다음은 같은 기능을 수행하는 코드를 각각 반복문과 재귀로 구현한 것이다.
```cpp
//반복문
void line(int n) {
    while (n >= 1) {
        cout << "*";
        n--;
    }
    return;
}
```
```cpp
//재귀
void line(int n) {
    if (n < 1) return;
    cout << "*";
    line(n-1);
}
```
주로 재귀함수는 팩토리얼이나 피보나치 수 등의 반복적으로 계산되며 점점 작아지는 문제를 풀 때 유용하게 쓰인다. 다음은 특정 범위와 수의 피보나치 수를 재귀로 구현한 것이다.
![화면 캡처 2024-07-04 193110](https://github.com/gkeksd/codding-archive/assets/54362230/5b3e53ce-732c-4b33-9fc1-e4ecebe838bb)
```cpp
#include <iostream>
using namespace std;

long long fib(int n);

int main() {
    cout << "0~10 범위의 피보나치 수 테스트" << endl;
    for (int i = 0; i <= 10; i++) {
        cout << "fib(" << i << ") = " << fib(i) << endl;
    }
    cout << endl;

    cout << "35와 45 피보나치 수 테스트" << endl;
    cout << "fib(35) = " << fib(35) << endl;
    cout << "fib(45) = " << fib(45) << endl;

    return 0;
}

long long fib(int n) {
    if (n == 0 || n == 1)
        return n;
    else
        return fib(n - 2) + fib(n - 1);
}

```
이 코드는 정수 n에 대해 n-1과 n-2에 대한 자신의 함수를 호출해 더하고, n이 0이나 1에 도달했을 때 값을 그때부터 역으로 계산해나가기 시작하며 최종적인 값을 반환하는 구조로 되어 있다.
