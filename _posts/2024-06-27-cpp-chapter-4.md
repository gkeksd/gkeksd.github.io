## 연산자
### 비교 연산자
![화면 캡처 2024-06-27 190145](https://github.com/gkeksd/codding-archive/assets/54362230/86257b62-a055-4bc7-bd5f-9c2dc9097925)
비교 연산자는 전체 연산자의 우선순위에서 콤마 다음으로 가장 낮은 순위를 차지한다. 비교 연산자는 크게 관계 연산자와 일치 연산자로 나눌 수 있다. 관계 연산자는 두 값 사이의 대소를 비교하여 관계를 판정하는 연산자이고, 일치 연산자는 두 값이 동일한지 동일하지 않은지를 판정한다.
 * 부동소수점 값끼리 비교할 때에는 일치 연산자 ==를 쓰지 않는 것이 안전하다. 예를 들어 0.1 * 0.1 == 0.01은 성립하지 않는데, 그 이유는 컴퓨터의 값 표현 방식에서 기인한다.
 * 컴퓨터는 값을 2진수로 변환해 저장하는데, 컴퓨터가 메모리에 저장할 수 있는 한계보다 부동 소수점 값의 2진수 값 크기가 크기에 컴퓨터는 부동 소수점 값을 근사적으로 저장한다. 
 * 비교 표현식에서 boolean 값은 각각 숫자로 바뀌어 계산된다. 예를 들어 true는 1로, false는 산으로 계산된다.

## 제어문
제어문이란 코드의 실행을 제어하는 구문이다. 크게 조건문과 반복문으로 나뉜다.
### 조건문
조건문이란 제어문에 조건을 주어 그 조건이 참일 때 코드가 실행되도록 하는 구문을 뜻한다. C++에서 조건문은 크게 if문과 switch 문으로 나뉜다.
#### if문
**if 문은 조건이 참이면 그 문장을 실행하고, 조건이 거짓이면 다른 문장을 실행하는 구문이다.** 따라서 조건에는 문장의 참과 거짓을 도출해낼 수 있는 표현식을 사용한다. if문은 기본적으로 다음의 구조로 이루어진다.
![화면 캡처 2024-06-27 191611](https://github.com/gkeksd/codding-archive/assets/54362230/4b738e51-ee6d-441c-9074-d8e7ab56ffc4)
```cpp
if (조건) {
    문장
}
```
다음은 if 문을 시행할 때 주의할 점이다.
 * 조건에 할당 연산자 =을 표현할 경우, 그 조건은 항상 거짓이 되어 중괄호 안의 문장은 언제나 실행되지 않는다.
 * if문에서 중괄호를 생략한 경우, 첫번째 문장만이 해당 조건에 영향을 받아 실행되고 두번째 이후의 문장들은 조건의 참거짓에 관계 없이 항상 실행된다.
 * if문에서 조건 뒤에 세미콜론을 찍으면 세미콜론을 찍은 if (조건); 자체가 하나의 문장으로서 완결되어, 중괄호가 있는지의 여부와 관계없이 저 문장이 실행되어 아무런 작업을 수행하지 않으며, 조건문의 문장들은 항상 실행된다.

#### if-else 문
![화면 캡처 2024-06-27 192408](https://github.com/gkeksd/codding-archive/assets/54362230/c0a082dc-6407-4ce4-bea0-8a83109328e5)
if-else 문은 이 그림과 같이 if 문의 조건이 거짓일 경우 else 문이 실행되어 else 문의 문장이 실행되는 구문이다. if-else 문은 다음의 구조를 가진다.
```cpp
if (조건) {
    문장1;
}
else {
    문장2;
}
```
이 구문은 if문의 조건에 해당하는 경우에는 문장1이, if 문의 조건에 해당하지 않는 모든 경우에 대해 문장2가 실행된다.
 * 만약 if-else 문에서 if의 조건 뒤에 세미콜론을 찍었을 경우, 전과 마찬가지로 if(조건); 자체가 하나의 문장으로 취급되므로 else 문은 if문이 없는 else 문으로 취급되어 컴파일 오류가 발생한다.

#### 이중 if-else 문
![화면 캡처 2024-06-27 192958](https://github.com/gkeksd/codding-archive/assets/54362230/54042dbf-4a1e-462d-a473-9399d4674c62)
이중(중첩) if-else 문은 if 문과 else 문 속에 각각 if-else 문이 이중으로 존재하는 구문이다. 따라서 if-else 문의 구조에 따라 전체 구문의 표현식은 총 3개, 문장은 총 4개가 된다. 일반적으로 첫 번째 if-else 문에는 문장을 적지 않기도 하나, 그렇지 않은 경우도 있다.

else 문은 중괄호로 구분되지 않을 때 일반적으로 가장 가까운 if문과 짝지어지기에, 다음의 코드에서 else 문은 두 번째 if 문과 짝지어져 논리 오류가 발생한다.
```cpp
if(표현식1)
    if(표현식2)
        문장
else
    문장2
```
이 코드는 다음과 같이 고쳐야 제대로 동작한다.
```cpp
if(표현식1) {
    if(표현식2) {
        문장1
    }
}
else {
    문장2
}
```

#### if-else if문
![화면 캡처 2024-06-27 194120](https://github.com/gkeksd/codding-archive/assets/54362230/3ca77aaf-9df4-416e-951d-1ad7898ce74b)
if-else 문에 더해 else if를 사용함으로서 두 가지 이상의 더 많은 분기에 대해서도 제어할 수 있다.

if-else if문은 일반적으로 다음의 코드와 같은 구조를 가진다.
```cpp
if (조건1)
 문장 1;
else if (조건2)
 문장 2;
else if (조건3)
 문장 3;
else if (조건4)
 문장 4;
else
 문장 5
```
#### 논리 표현식(Logical expression)
2개 이상의 피연산자 중 최소 하나가 bool 자료형이고, 연산 결과 최종적으로 bool 자료형을 생성한다. !(NOT, 논리 부정), &&(AND, 논리곱), ||(OR, 논리합)의 세 가지 논리 연산자를 사용한다.
![화면 캡처 2024-06-28 122708](https://github.com/gkeksd/codding-archive/assets/54362230/09734715-bb64-49d1-b2f1-c693402c484e)
 * NOT 연산자는 피연산자가 false 일때 false의 반대 true를, 피연산자가 true일때 true의 반대 false를 출력한다.
 * AND 연산자는 피연산자 두개가 모두 true일 때 true를 출력하고, 그 이외에는 모두 false를 출력한다.
 * OR 연산자는 피연산자 두개가 모두 false일 때 false를 출력하고, 그 이외에는 모두 true를 출력한다.

특정 범위 내의 값을 설정하고자 할 때는, 수학에서처럼 1 <= x <= 3으로 쓰지 않고 &&연산자를 사용하여 1 <= x && x <= 3으로 출력한다.

한편 서로 겹치지 않는 두 범위 중 하나에 대한 논리연산을 수행하고자 할 때는 ||연산자를 사용한다.

예를 들어 윤년인 해를 계산하고자 할 때는, 연도를 400으로 나누어 떨어지거나, 연도를 4로는 나누어 떨어지지만 100으로는 나누어 떨어지지 않을 때 윤년이므로 다음과 같은 논리연산을 짠다.
```cpp
leapYear = (year % 400 == 0) || (year % 4 == 0) && !(year % 100 == 0));
```
따라서, 다음과 같은 코드를 설계할 수 있다.
```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    bool leapYear;

    cout << "연도를 입력하세요: ";
    cin >> year;

    leapYear = (year % 400 == 0) || (year % 4 == 0 && !(year % 100 == 0));

    if (leapYear)
        cout << year << "년은 윤년입니다." << endl;
    else
        cout << year << "년은 윤년이 아닙니다." << endl;

    return 0;
}
```

#### switch 문
![화면 캡처 2024-06-28 124036](https://github.com/gkeksd/codding-archive/assets/54362230/9d6bcfed-4b3d-434b-a357-94d598fbdc35)
switch 문은 if 문과는 달리 표현식이 **특정 값을 가질 때** 분기하는 조건문의 일종이다. 따라서 switch-case 문의 구조로 이루어진다. 다음은 전형적인 switch문의 구조이다.
```cpp
switch(표현식) {
    case 값1: 문장1;
    case 값2: 문장2;
    case 값3: 문장3;
    case 값4: 문장4;
}
```
이때 표현식의 값이 값2라면, 값1의 case를 건너뛰고 값2의 case부터 실행한다. case에 break문이 없을 때, switch 문은 해당하는 case 이하의 값에 해당하는 문장들까지 모두 실행한다. 즉, 이 경우 문장2, 문장3, 문장4가 모두 실행된다.

#### switch-break 문
![화면 캡처 2024-06-28 124501](https://github.com/gkeksd/codding-archive/assets/54362230/3cf3157f-0461-4920-89ed-522bf2d42286)
위와 같은 문제를 해결하기 위해, switch 문이 표현식의 값에 해당하는 case만 실행하도록 case 문의 끝에 break;를 추가한 switch-break 문이 일반적으로 많이 사용된다. 즉 switch-break 문은 다음과 같은 구조를 일반적으로 가진다.
```cpp
switch(표현식) {
    case 값1: 문장1; break;
    case 값2: 문장2; break;
    case 값3: 문장3; break;
    case 값4: 문장4; break;
}
```
따라서 만약 표현식의 값이 값2일 때, 이에 해당하는 문장2 만을 실행하고 break 문을 만나 조건문을 탈출한다.

#### switch-default 문
switch-default 문은 case 문의 값들 중에 표현식의 값이 해당하는 것이 없을 때, case 문의 값들 이외에 다른 모든 경우에 실행되도록 default 문을 사용한다. default 문은 실행 후 바로 조건문을 탈출할 수 있도록 switch 문의 가장 마지막에 놓는다. switch-default 문은 다음과 같은 구조로 이루어진다.
```cpp
switch(표현식) {
    case 값1: 문장1; break;
    case 값2: 문장2; break;
    case 값3: 문장3; break;
    case 값4: 문장4; break;
    default: 문장5;
}
```

#### 조건문 삼향 연산자
C++에서 유일하게 사용되는 삼향 연산자로, if-else 문을 한줄에 써야 할 때 사용한다. 삼향 연산자는 다음의 구조로 이루어진다
```cpp
조건 ? 표현식1 : 표현식2;
```
이는 조건이 참(true)일 경우 표현식1을, 거짓(false)일 경우 표현식2를 실행한다는 의미이다. 이 삼향 연산자는 if-else 문과 같은 기능을 수행하지만 이와는 다르게 다른 문장의 일부로 사용할 수도 있다.
