## 참조자 타입
6장에서 배운 참조자 타입을 확장시켜, 일반적인 변수 등의 인스턴스를 선언할 때에 자료형 뒤에 &기호를 붙임으로서 참조 타입임을 명시할 수 있다. 이렇게 선언된 참조자 타입의 변수에 기존의 Lvalue 변수를 할당함으로서 해당 피할당 변수의 **새로운 이름**을 붙일 수 있다. 즉 다음과 같이 사용한다.
```cpp
int a = 5;
int& b = a;
cout << a << " " << b; //5 5
```
이때 참조자 타입의 변수에 Rvalue값을 할당해서는 안되며, 피할당 변수와 같은 자료형의 참조자 타입 자료형으로 선언해야 한다. 만약 Rvalue의 값을 참조자 타입에 할당하고 싶다면, 다음과 같이 &를 두 개 붙인 이동 시멘틱(Move simentics)을 사용해 해결할 수 있다.
```cpp
int&& a = 5;
cout << a; //5
```

이 사진은 참조자 타입의 유형별로 const 한정자를 붙이는 경우 및 해당 조건마다 오류가 나는지의 여부를 정리한 것이다.

## 메모리 주소
메모리에서 접근 가능한 가장 작은 단위는 바이트(byte)로, 메모리 주소는 이러한 바이트의 연속이다. 킬로바이트, 메가바이트, 기가바이트, 테라바이트 등의 단위가 존재하며, 각각 2의 10제곱씩 곱해 구할 수 있다. 각각의 메모리 1개 주소에는 16진수로 표현되는 주솟값이 존재한다. 예를 들어, 1kb의 메모리 주소에는 0x000부터 0x3ff까지의 메모리 주소가 연속적으로 배치되어 있다.

모든 자료형들은 환경에 따른 일부 예외를 제외하면 크기가 정해져 있다. 변수는 자료형의 종류에 따라 최소 1바이트 이상의 메모리 공간을 차지하며, 이는 sizeof 함수를 통해 확인할 수 있다.

우리가 변수의 메모리 주소를 구하고자 할 때 출력되는 값은 그 변수의 메모리 주소가 **시작되는** 주솟값이다. 이를 구하고자 한다면 변수이름을 출력할 때 앞에 &를 붙여 다음과 같이 사용한다.
```cpp
int a = 5;
cout << &a;
```

## 포인터 타입
포인터 타입은 리터럴이 값이 아닌 그 값의 메모리 주소값으로 가지는 자료형으로, 변수를 선언할 때 할당할 값의 자료형 뒤에 *기호를 붙인다. 어떤 자료형에 대한 포인터 타입이라도 그 크기는 64비트 윈도우 기준으로 8바이트이다.
```cpp
bool* pFlag;
int* pScore;
double* pAverage;
```

포인터 변수는 별도의 캐스팅 과정 없이는 리터럴을 저장하는 것이 불가능하며, 메모리 주소가 저장된다. 대부분의 경우 기존에 존재하는 변수의 메모리 주소로 초기화된다. 이러한 초기화는 동일한 자료형에 대한 주소값 초기화만이 가능하다.
```cpp
bool* pFlag = &Flag;
int* pScore = &Score;
double* pAverage{&Average};
```

### 역참조 연산
![화면 캡처 2024-07-14 140321](https://github.com/user-attachments/assets/8886b672-6d2d-431c-b1b4-908c7a0c48bb)
간접 참조 연산이라고도 부른다. 포인터 타입의 변수에서 특정 그 포인터가 가리키는 메모리 주소의 값에 접근하고자 할때 포인터 변수의 이름 앞에 *를 붙여서 사용한다. &를 사용한 기본 참조 연산이 해당 피할당 변수의 새로운 이름을 생성하는 개념이라면, 역참조 연산은 포인터를 이용해 해당 피할당 변수의 주소만을 가져다 새로운 변수를 만들어 저장한 것을 다시 역으로 참조하여 값을 가져온다.

역참조 연산을 사용해 그 포인터 변수를 통해 가리키는 변수의 값까지 수정할 수 있다. 다음 예제를 통해 확인할 수 있다.
```cpp
#include <iostream>

int main() {
    int value = 42;       // 정수 변수 선언 및 초기화
    int* ptr = &value;    // 변수의 주소를 저장하는 포인터 선언

    // 포인터를 사용하여 변수에 접근
    std::cout << "Original value: " << value << std::endl;  // 출력: 42
    std::cout << "Pointer value: " << *ptr << std::endl;    // 포인터를 통해 접근한 값 출력: 42

    // 포인터를 사용하여 변수 값 수정
    *ptr = 100;
    std::cout << "Modified value: " << value << std::endl;  // 출력: 100
    std::cout << "Pointer value: " << *ptr << std::endl;    // 포인터를 통해 접근한 값 출력: 100
}
```

![화면 캡처 2024-07-14 141401](https://github.com/user-attachments/assets/d3e0c446-ff04-492d-a556-422c8155c29a)
&기호를 자료형 뒤에 붙이는 것은 참조자 타입이며, 변수 이름 앞에 붙이는 것은 해당 변수의 메모리 주소를 뜻한다. 한편 자료형 뒤에 *기호를 붙이는 것은 포인터 타입을 뜻하며, *를 변수 이름 앞에 붙이는 것은 역참조를 뜻한다.

### 포인터 타입을 이용한 pass-by-reference
함수에서 매개변수를 통해 인자를 전달할 때, 해당 인자의 주솟값을 가리킬 수 있는 포인터 타입 변수를 생성한 후 함수 호출 시 인자가 전달되면 포인터 변수에 해당 인자의 주솟값을 복사해 사용한다. 그 함수 내에서 역참조 연산을 사용하면 주솟값을 가져온 그 인자의 값을 역참조할 수 있으며, 값 변경도 가능하다.
```cpp
#include <iostream>
using namespace std;

void fun(int* y);

int main() {
    int x = 10;
    fun(&x);
    cout << "main 함수 내부의 x = " << x << endl; //11
}

void fun(int* y) {
    (*y)++; //역참조 연산을 통해 x의 값 1 증가
    cout << "fun 함수 내부의 y = " << *y << endl; //11
}
```
이 예제 코드에서 fun함수의 매개변수인 포인터 변수 y는 x 변수를 인자로 전달받아 그 주솟값을 참조한 후, 함수 내에서 역참조 연산을 통해 그 인자의 값을 1 증가시킨다. 함수 호출이 종료된 후 main 함수에서 x의 값을 출력해보면 1 증가시킨 값인 11로 출력된다.

#### swap
```cpp
#include <iostream>
using namespace std;

void swap(int* first, int* second);

int main() {
    int x = 5;
    int y = 16;
    
    cout << "스왑하기 전의 x와 y의 값" << endl;
    cout << "x: " << x << "    " << "y: " << y << endl;
    
    swap(&x, &y);
    
    cout << "스왑 후의 x와 y의 값" << endl;
    cout << "x: " << x << "    " << "y: " << y << endl;
}

void swap(int* pX, int* pY) {
    int temp = *pX;
    *pX = *pY;
    *pY = temp;
}
```
포인터 변수를 이용해 pass by reference 방식으로 인자를 전달받은 후 역참조 연산으로 값을 바꾸고, 이후 main 함수에서 뒤바꾼 값을 출력한다.

#### return
포인터 변수를 return 하는 함수에 대해 리턴된 값을 할당하려면 포인터 변수를 만들어 할당하거나, 일반 변수에 할당하되 그 함수에 역참조 연산을 할 수 있다.
```cpp
#include <iostream>
using namespace std;

int* larger(int* x, int* y) {
    if (*x > *y)
        return x;
    return y;
}

int main() {
    int x = 5;
    int y = 16;

    int* r = larger(&x, &y);
    cout << (*r)++ << endl;
    cout << y << endl;

    int i = *(larger(&x, &y));
    cout << i++ << endl;
    cout << y << endl;
}
```

### 상수 포인터
상수 포인터는 포인터 변수에 const를 붙여서 선언할 수 있다. const를 붙이는 위치에 따라 기능이 다르다.
![화면 캡처 2024-07-14 144925](https://github.com/user-attachments/assets/e4233849-0f38-47ee-9c04-3d76349e47ea)
포인터 변수에서 자료형 앞에 const를 붙일 경우 간접 참조 방식으로 주소를 참조하며, 값의 변경이 불가능하다. 한편 포인터 변수의 이름 앞에 const를 붙일 경우 한번 주소를 참조한 이후 변경할 수 없다.

상수 포인터는 참조하려는 변수가 상수일 때 일반 포인터로는 참조할 수 없으므로 사용하며, 데이터 멤버와 상수 포인터 모두 값을 변경할 수 없다. 한편 참조하려는 변수는 변수인데 포인터는 상수라면 포인터 변수로는 값을 변경할 수 없다. 

### 이중 포인터(Double pointer)
![화면 캡처 2024-07-14 145611](https://github.com/user-attachments/assets/86a2659a-66e0-423c-9de6-65945a35f047)
이중 포인터는 *가 두번 붙은 포인터 변수 타입으로, 포인터를 참조하는 포인터이다. 사용법 자체는 일반 포인터 변수와 유사하다. 이중 포인터는 다음과 같이 선언한다.
```cpp
int a = 5;
int* b = &a;
int** c = &b;
```
이중 포인터 변수에서 참조한 주소와 값을 가져오는 방법은 다음과 같다.
```cpp
cout << *c << "\n"; //변수 a의 주솟값
cout << *(*c); //역참조 연산. a의 값
```
즉 이중 포인터의 역참조 연산은 이중으로 이루어진다.

### nullptr / void*
 * 널 포인터(null pointer): 널 포인터란 아무것도 참조하지 않는 포인터를 말한다. c언어의 경우 널 포인터 변수에 0이나 NULL을 할당해 정의하지만, C++은 nullptr을 통해 정의한다. 불리언 연산에서 널 포인터는 false로 판정된다.
 <br>
 * void*(void pointer): 모든 자료형을 참조할 수 있는 포인터 타입을 void 포인터라고 한다. 주로 참조할 변수의 자료형이 불명확하거나 서로 다른 자료형의 변수를 여러개 참조해야 할 때 사용한다. 이 포인터는 참조 대상의 자료형에 대한 정보가 없으며, 역참조 연산은 불가능하다.

## 예제
포인터와 클래스, 멤버 접근 연산자를 활용한 예제이다.
```cpp
#include <iostream>
using namespace std;

class Tmp {
private:
  int a = 5;
public:
  void setA() { a++; }
  int getA() const { return a; }
};

Tmp fun1(Tmp t) {
  return t;
}
Tmp& fun2(Tmp& r) {
  return r;
}
Tmp* fun3(Tmp* p) {
  return p;
}

int main() {
  Tmp t;
  fun1(t).setA();
  cout << t.getA() << "\n"; // 5
  fun2(t).setA();
  cout << t.getA() << "\n"; // 6
  fun3(&t)->setA();
  (*fun3(&t)).setA();
  cout << t.getA() << "\n"; // 8
}
```
이 코드는 함수 반환 타입에 따라 객체의 조작 방식이 어떻게 달라지는지에 대한 예제이다. 값 반환은 원본에 영향을 주지 않지만, 참조나 포인터 반환을 통해 객체의 값을 집적 조작할 수 있다.

Tmp 클래스에서 setA() 메서드는 a를 1 증가시키고, getA() 메서드는 a의 값을 반환한다.

한편 fun1 함수는 값으로 전달받고 값을 반환하고, fun2 함수는 참조로 전달받고 참조를 반환한다. fun3 함수는 포인터로 전달받고 포인터를 반환한다.

main 함수 영역에서 Tmp 클래스의 객체 t를 생성한다. 그 후 fun1(t).setA()는 fun1에 전달된 객체 t에 대해 setA함수를 호출해 나온 값을 저장한다. pass by value이므로 t의 복사본이 생성되고, 그 복사본에 대해 setA()가 호출된다. 데이터 멤버 a가 객체 t에 저장되지만 후위 증감 연산자이므로 값이 바뀌지는 않는다.

두번째로 fun2 함수는 객체가 참조로 전달되므로 원본 t에 대해 setA()가 호출된다. t에 저장된 a가 6으로 증가한다. 세번째 fun3 함수는 객체가 포인터로 전달되므로 원본 t에 대해 setA()가 호출된다. t의 a가 7로 증가한다. (*fun3(&t))는 객체가 포인터로 전달된 후 역참조되어 원본 t에 대해 setA()가 호출된다. t의 a가 8로 증가한다.
