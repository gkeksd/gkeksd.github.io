## 표현식(Expression)
![표현식 종류](https://github.com/gkeksd/codding-archive/assets/54362230/335a298a-efae-4090-9cf4-1455f8321af2)
표현식이란 특정 값을 가진 개체로, 값으로 표현될 수 있는 모든 문장은 표현식이다. 

예를 들어, 
```cpp
int a = 5;
cout << a;
```
이 코드에서 두번째 줄의 문장이 표현식이다.

 * 부가 효과(side effect): 값을 변경하는 행위 등을 통해 메모리의 상태를 조작(변경)하는 행위

### 기본 표현식
기본 표현식이란 연산자 없이 구성된 가장 간단한 표현식으로, 더 복잡한 표현식을 구성하는 기초가 된다.
 * **리터럴**: 값은 나타내지만 추가적인 부가 작용이 없는 표현식. 모든 리터럴은 내부적으로 자료형을 가짐.
 * **식별자**: 변수, 클래스, 함수 등의 이름
 * **괄호 표현식**: 우선순위가 낮은 연산자로 구성된 표현식이 괄호로 묶였을 때 우선적으로 계산함

#### 리터럴 표현식
다음의 예제 코드에서 각각 출력하는 대상들 및 공백 문자가 리터럴에 해당됨

 ```cpp
#include <iostream>
using namespace std;

int main() {
    cout << false << " " << 'A' << " " << "Hello!" << endl;
    cout << 23412 << " " << 12897234L;
    cout << 245.78F << " " << 114.782 << " " << 2.051L;
}
```
이 코드의 표현식들은 값을 나타내지만, 연산을 추가적으로 수행하는 등의 부가 효과가 일어나지 않기에 리터럴에 해당

#### 괄호 표현식
다음의 예제 코드에서 괄호에 묶인 부분이 괄호 표현식에 해당됨.
 ```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 4

    cout << "괄호가 있는 경우의 값: " << (x + 3) * 4; //28
    cout << "괄호가 없는 경우의 값: " << x + 3 * 4; //16
}
```
이 코드에서 괄호 안의 표현식은 괄호가 없을 때에는 우선순위가 곱셈(*) 연산자에 밀리지만, 괄호 덕분에 우선순위로 연산을 수행하기에 괄호 표현식에 해당

#### sizeof 표현식
다음의 예제 코드에서 sizeof 함수가 쓰이는 부분이 sizeof 표현식에 해당됨
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(char) << endl;
    cout << sizeof(short) << endl;
    cout << sizeof(int) << endl;
    cout << sizeof(long) << endl;
    cout << sizeof(long long) << endl;
    cout << sizeof(float) << endl;
    cout << sizeof(double) << endl;
    cout << sizeof(long double) << endl;
    cout << sizeof(2 * 5.1) << endl;
}
```
이 코드는 각 자료형들과 계산 값의 메모리 크기를 측정하는 기능을 수행하기에 sizeof 표현식에 해당됨.

#### 곱셈 표현식
 * 곱셈: 두 개의 값을 곱할 때는 * 기호를 사용함. 이때 피연산자 두개의 자료형이 다르다면, 한 피연산자의 자료형이 다른 피연산자의 자료형으로 변환됨
 ex)2 * 3.14의 경우 int형인 2의 자료형을 double로 변환해 결과가 double 타입으로 나옴
 * 나눗셈: 두 값을 나눌 때는 / 기호를 사용함. 피연산자 두 개가 모두 정수라면 값이 나머지나 소수점이 없는 정수 몫으로 나오지만, **피연산자 중 하나라도 부동 소수점이 있는 실수 자료형(double 등)이라면 값도 부동 소수점으로 나옴.**
 * 나머지: 두 값의 나머지를 구할 때는 % 기호를 사용함. 피연산자 두 개가 모두 정수일 때에만 사용 가능.

 ```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "곱셈 연산자 확인하기" << endl;
    cout << "3 * 4 = " << 3 * 4 << endl; //12
    cout << "2.4 * 4.1 = " << 2.4 * 4.1 << endl; //9.84
    cout << "-3 * 4 = " << -3 * 4 << endl << endl; //-12

    cout << "나눗셈 연산자 확인하기" << endl; 
    cout << "29 / 5 = " << 29 / 5 << endl; //5
    cout << "29.0 / 5 = " << 29.0 / 5 << endl; //5.8
    cout << "29 / 5.0 = " << 29 / 5.0 << endl; //5.8
    cout << "4 / 7 = " << 4 / 7 << endl << endl; //0

    cout << "나머지 연산자 확인하기" << endl; 
    cout << "30 % 5 = " << 30 % 5 << endl; //0
    cout << "30 % 4 = " << 30 % 4 << endl; //2
    cout << "3 % 7 = " << 3 % 7 << endl; //3
}
```

#### 할당 표현식
##### 기본 할당 표현식
![화면 캡처 2024-06-26 164923](https://github.com/gkeksd/studyCPP/assets/54362230/6f57a587-4b03-4ec8-9bcd-986f45e183e8)
할당 연산자 =을 기준으로 왼쪽과 오른쪽에만 요소가 존재하는 기본적인 할당 표현식으로, 오른쪽의 값이 왼쪽의 변수 등에 할당되며 부가 효과로 값을 덮어씀. 

한편 cout 등 출력 함수에 x=14 등의 할당 표현식을 사용할 경우, 식을 괄호로 감싸지 않으면 에러가 발생함.

##### 복합 할당 표현식
![스크린샷 2024-06-26 102104](https://github.com/gkeksd/studyCPP/assets/54362230/0710becb-7203-485b-be7a-2d64855ebc82)

할당 연산자를 기준으로 왼쪽과 오른쪽에 모두 요소가 존재하지만, 왼쪽과 오른쪽 모두에 동일한 변수 등이 존재하는 표현식. 즉 x = x + 5등이 복합 할당 표현식에 해당함. 이 경우 x += 5 등으로 줄여서 씀. 연산자 오른쪽에서 기존 변수의 값에 연산이 이루어지고 난 후, 연산자 오른쪽의 변수에 바뀐 값이 저장되며 덮어써짐. 앞의 표현식에서 만약 초기값이 x = 4였다면, 할당 연산의 결과로 x = 9가 새로 저장됨.

## 자료형 변환(Data type Conversion)
### 암시적 형변환(Implicit type Conversion)
컴파일러가 알리지 않고 **자동으로 기본 자료형을 다른 자료형으로 바꾸는 경우**를 암시적 형변환이라고 한다. 주로 변수의 자료형과 다른 값을 저장했을 때나 서로 다른 자료형끼리 계산을 수행할 때 사용된다.

![화면 캡처 2024-06-26 170305](https://github.com/gkeksd/studyCPP/assets/54362230/d3547bf9-885d-45df-b5ce-68ba4ba2d9de)
 * 승격(promotion): 한 자료형의 값이 더 큰 유사한 자료형의 값으로 변환됨. 데이터 손실 없이 안전함
 ex) bool 형이나 char 형, short 형이 int 형으로, int 형이 long 형이나 long long 형으로, float 형이 double 형으로 변환하는 경우
 * 변환(conversion): 승격을 제외한 모든 경우. 더 큰 자료형에서 더 작은 자료형의 값으로의 변환이나 아예 다른 자료형으로의 변환. 데이터 손실이 발생함.
 ex) int 형에서 double 형으로의 변환 등
 * 이외에 부호가 있는 자료형에서 부호가 없는(unsigned) 자료형으로의 변환도 이루어짐. 
 * 따라서 부호가 있는 자료형과 부호가 없는 자료형을 계산할 때, 부호가 있는 값의 2진수 형태를 다시 부호가 없는 자료형의 10진수 값으로 변환하는데 그 값이 Max(최대값) - 1로 변환되기에, 계산 결과에 오류가 발생함.
 * typeinfo 헤더 파일 추가 후 아래 코드를 통해 표현식의 자료형 확인 가능
 ```cpp
 typeid(expression).name()
 ```

### 명시적 형변환(Explicit type Conversion)
프로그래머가 **한 자료형을 원하는 자료형으로 명시적으로 변환**하는 것. 개발자의 의도에 따라 변환됨. 캐스팅(casting)이라고도 부름. C++에서 casting은 크게 C-style casting, static casting, const casting, dynamic casting, reinterpret casting으로 나뉘는데, 이 중
```cpp
static_cast<type>(expression)
```
위와 같은 형태의 코드를 통해 static casting을 수행함. 이 캐스팅 방법은 C-style casting과는 다르게 컴파일 시간에 컴파일러가 타입 검사를 수행하기에 실수로 인한 에러를 줄일 수 있음.

## 오버플로우/언더플로우(Overflow/Underflow)
![화면 캡처 2024-06-26 171839](https://github.com/gkeksd/studyCPP/assets/54362230/b393e88c-4759-46bb-8364-fae96001f0a7)
컴퓨터 프로그램에서 사용하는 자료형에는 다루는 숫자의 범위가 한정되어 있는데, **자료형의 최대값보다 크거나 최소값보다 작은 값을 다루려고 할 때 발생하는 오류**를 오버플로우/언더플로우라고 한다. C++ 컴파일러는 이 오류에 대해 에러 메시지를 띄우지 않기에 프로그램 실행 시 예기치 못한 결과를 만들어낸다.

위의 그림 3-9와 같이, 오버플로우 발생 시 컴파일러는 그 값을 가장 작은 값으로 바꾸어서 출력하며, 반대로 언더플로우 발생 시 컴파일러는 그 값을 가장 작은 값으로 바꾸어서 출력한다.

## 조정자(Manipulator)
```cpp
cout << 조정자 << 변수;
cin >> 조정자 >> 변수;
```
위의 코드와 같이 쓰며 프로그램의 입출력 형식을 기본에서 변경하고자 할 때 쓰는 것을 조정자라고 한다. 이때 코드는 << 또는 >> 연산자의 방향에 따라 동작한다.

조정자는 데이터 출력 조정자와 데이터 입력 조정자로 구분된다.

### 출력 조정자
![화면 캡처 2024-06-26 172357](https://github.com/gkeksd/studyCPP/assets/54362230/ada667c2-9822-450f-bbc5-c2bd775c7491)
매개변수가 필요 없으며 값을 출력할 때 쓰는 조정자를 출력 조정자라고 한다.
 * endl: \n과 같은 효과. 다음 줄로 넘어감.
 * boolalpha: bool자료형의 값을 1과 0 대신 true와 false로 출력해줌
 * dec, oct, hex: 2진수로 값을 읽고 처리하는 컴퓨터가 출력시 각각 10진수/8진수/16진수로 처리하게 해주는 조정자
 * showbase: 값의 앞에 진법을 표시하는 조정자. 10진수는 아무것도 붙지 않으며 8진수는 0, 16진수는 0x가 접두사로 붙음.

실수 표기법 관련 조정자
 * showpoint: 값을 유효숫자 여섯 자리로 표기하게 해주는 조정자. 실수(double 등)일때 사용
 * fixed, scientific: 각각 고정 소수점 6자리, 과학적 표기법(자연로그의 밑 표기법)으로 값을 나타내는 조정자

값 정렬 관련 조정자
![화면 캡처 2024-06-26 173216](https://github.com/gkeksd/studyCPP/assets/54362230/d1da9327-90b7-4e42-9f00-679850e4daa8)
 * left, internal, right: 값을 표현하는 정해진 영역의 필드에서의 배치 방식을 조정하는 조정자. 배치 방식은 그림 3-12 참고.
 * setprecision: 부동 소수점에만 사용가능하며, 매개변수가 한 개 필요함. 숫자를 표현하는 정밀도(소숫점 아래 자릿수)를 조정하는 조정자. 표현하는 자릿수 바로 뒤에서 반올림함.
 * setw: 출력을 위한 필드의 전체 크기를 조정하는 조정자. 매개변수 한 개 필요함.
 * setfill: 필드 내에서 값 이외의 빈 영역에 해당하는 패딩(padding)문자(기본은 공백)를 설정하는 조정자. setfill('+')로 설정했을 경우 필드 내 패딩 영역이 + 문자로 채워짐

### 입력 조정자
 * boolalpha: cin 함수로 입력 받을 시에도 사용 가능. 1과 0 대신 true와 false로 입력해 1과 0으로 처리하게 해줌.(불 자료형은 1과 0만 입력할 수 있음)
 * oct/hex: 8진법/16진법으로 입력 받아 10진법으로 출력
