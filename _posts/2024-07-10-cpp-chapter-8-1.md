## 내장 배열(built-in array)
![화면 캡처 2024-07-10 203929](https://github.com/gkeksd/codding-archive/assets/54362230/73924db7-4a98-4a59-a290-ddca6baec668)
내장 배열이란, 동일한 자료형을 가진 연속적은 메모리 공간들의 집합이다. 만약 같은 int 타입을 가진 메모리 공간들이 a부터 z까지 연속적으로 있을 때, 우리는 이를 각각의 변수로 선언해도 되지만 배열을 이용해 이 공간들을 하나로 묶음으로서 개발의 효율성을 훨씬 높일 수 있다.

배열의 특정 요소에 접근하고자 할 때는 배열의 이름과 연속적인 공간 안에서 그 요소의 위치를 대괄호([])로 감싸 접근할 수 있다.

배열에서 특정 원소가 가진 위치는 subscript 또는 index라 부르며, 1이 아닌 **0부터 시작**한다. 배열에서는 처음 선언할 때 길이를 한번 확정지으면 그 이후로는 동적 배열을 제외하고는 일반적으로 변경이 불가하다. 또한 배열의 개별 요소 또한 일반적으로 한번에 바꾸거나 삭제, 추가할 수 없다. 즉 정적 배열(static array)에 해당한다.

### Out of range
C++언어의 컴파일러는 코드를 컴파일할 때 배열에 접근할 때 인덱스에서 벗어났는지의 여부를 검사(bound check)하지 않는다. 따라서 무심코 배열의 범위를 벗어난 접근을 하면 버퍼 오버플로우 오류가 발생할 수 있으며, 이는 보안상의 문제와도 직결되기에 반드시 배열의 범위를 지켜야 한다.

버퍼란 메모리에서 어떠한 데이터를 임시적으로 저장하기 위한 장소인데, 컴파일 과정에서는 컴파일을 통해 저장된 변수나 배열 등의 데이터를 버퍼에 저장한다. 그런데 배열의 범위에 벗어난 접근을 하면 버퍼의 크기보다 더 크게 데이터가 들어가게 되는데, 이때 컴퓨터는 이 데이터를 기존에 버퍼와 메모리에 있는 값에 **덮어쓴다.** 즉 버퍼의 칸 만큼에 해당하는 값들은 채운 후, 버퍼에 넘쳐서 들어가지 못한 겂은 메모리 공간에 할당되어 메모리의 값을 바꾼다. 이를 통해 해킹 등 보안 취약점 공략에도 활용할 수 있다.

비주얼 스튜디오에서 일반적으로 사용되는 디버그 모드(debug mode)에서 이러한 접근을 하면 오류가 발생하거나 범위에서 벗어난 요소에는 쓰레기 값이 나오는데, 릴리스 모드(release mode)에서는 정상적으로 값이 대입한 값으로 출력된다. 릴리스 모드는 프로그램의 배포를 위해 사용하는 모드이기에 디버그 모드에서 먼저 이에 대해 충분히 검사할 필요가 있다.

### 배열 초기화
내장 배열을 초기화하는 데에는 여러가지 방법이 있다.
```cpp
int a[5]; //초기화 안함
int b[5]{1, 2, 3, 4, 5}; //배열의 범위만큼 모두 참
int c[5] = {1, 2}; //나머지 세 영역은 0으로 자동으로 채워짐.
int d[] = {1, 2, 3, 4, 5}; //크기에 자동으로 컴파일러가 초기화된 요소의 개수만큼 채움.
int e[5]{}; //컴파일러가 자료형별로 자동으로 설정한 값으로 채움. 
// int 형의 경우 모두 0으로 채움.
```

## 고정 길이 배열
위에서도 보았듯 c++에서 배열은 일반적인 경우 길이가 고정적이며, 변경할 수 없다. 따라서 배열을 선언할 때에는 길이를 무조건 상수나 Lvalue로 주어야 한다.

배열의 길이를 선언할 때는, 배열의 크기를 변경해야 할 때를 대비해 길이를 상수에 저장한 후 그 상수를 길이로 쓰는 것을 추천한다. 즉, 다음과 같이 써야 한다
```cpp
const int SIZE = 5;
int arr[SIZE];
```

## 범위 기반 반복
for 문을 통해 반복문을 사용할 때, 변수와 인덱스가 필요 없이 자동으로 배열의 모든 원소에 대해 반복을 수행하개 할 수 있다. 범위 기반 반복은 다음과 같이 진행한다,
```cpp
int arr[5];
int number{0};
for(int& element : arr) element = ++number;
for(int element : arr) cout << element << "\n";
```
&을 통해 pass by reference 방식으로 반복을 수행하는 경우, 지역 변수의 값을 변경시킴으로서 배열의 요소를 할당할 수 있다. 반면 일반적인 pass by value 방식으로 할 수 있다.

## 배열과 함수 호출
![화면 캡처 2024-07-10 211050](https://github.com/gkeksd/codding-archive/assets/54362230/dc957f25-e9f8-4878-899b-9056fbd266ed)
배열을 함수에서 매개변수로 호출할 때, 매개변수의 메모리에서 배열의 각 요소가 담긴 시작 위치의 주소값만 전달하고 배열의 크기는 전달하지 않는다. 따라서 배열의 크기는 배열의 크기를 정의한 상수를 통해 별도의 매개변수로 전달해 주어야 한다. 참고로, 배열이 함수로 전달될 때는 오직 pass by reference 방식으로 전달된다. 또, 배열 타입으로는 리턴할 수 없다.
