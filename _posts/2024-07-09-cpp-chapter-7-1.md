## 클래스(Class)/객체(Object)/멤버(Member)
### 타입(type)/인스턴스(instance)
![화면 캡처 2024-07-09 095457](https://github.com/gkeksd/codding-archive/assets/54362230/342f03d0-18d2-46ba-b033-db27927007af)
인스턴스란 한 개의 타입을 이용해 만들어지는 것을 말한다. 여기서의 타입은 기본 자료형 뿐 아니라 클래스 등 사용자가 정의한 타입들도 포함된다. 변수 선언에서처럼, 하나의 타입을 이용해 여러 개의 인스턴스를 만들 수 있다.(ex. int a, b, c;)

### 클래스(Class)/객체(Object)
클래스를 만든다는 것은, Class라는 타입을 가진 사용자 정의 데이터 타입을 생성하는 것을 말한다. 따라서, 클래스도 type name; 형태로 생성이 가능하다. 이때 클래스라는 새로운 타입의 인스턴스로서 만들어진 것을 객체라고 한다. 즉 클래스는 타입이고, 객체는 인스턴스이다. 문자열을 저장하는 string 역시 대표적인 클래스 타입에 해당한다.

기본 자료형들과는 달리 클래스 형은 데이터(값) 뿐 아니라 관련 함수들까지 포함한다. 

### 데이터 멤버(data member)/멤버 함수(member function)
데이터 멤버란 클래스에서 정의되는 요소들 중 클래스 타입으로 선언되는 개별 객체들의 데이터를 저장하기 위해 정의된 변수를 이르는 말이다. 멤버 변수, 멤버 데이터라고도 부르며, 언어에 따라 필드(field)나 속성(attribute)이라고도 부른다. 이러한 데이터 멤버는 클래스 스코프(scope)를 가진다. 즉 선언된 위치부터 클래스가 종료되는 지점까지 정의된 코드 및 함수 등지에서 사용할 수 있다.

멤버 함수는 메소드(method)라고도 부르며, 클래스의 데이터나 개별 객체들을 처리하기 위해 정의된 함수를 이르는 말이다. 멤버 함수 역시 클래스 스코프를 범위로 한다.

다음의 코드는 이러한 데이터 멤버와 멤버 함수를 이용해 클래스를 구현하고 객체를 생성하는 예제이다.
```cpp
#include <iostream>
using namespace std;

class Circle {
private:
    double radius;
    const double PI = 3.14;

public:
    double getRadius() const;
    double getArea() const;
    double getPerimeter() const;
    void setRadius(double value);
};

double Circle::getRadius() const {
    return radius;
}

double Circle::getArea() const {
    return PI * radius * radius;
}

double Circle::getPerimeter() const {
    return 2 * PI * radius;
}

void Circle::setRadius(double value) {
    radius = value;
}

int main() {
    cout << "Circle 1" << endl;
    Circle circle1;
    circle1.setRadius(10.0);
    cout << "반지름: " << circle1.getRadius() << endl;
    cout << "넓이: " << circle1.getArea() << endl;
    cout << "둘레: " << circle1.getPerimeter() << endl;

    cout << "Circle 2" << endl;
    Circle circle2;
    circle2.setRadius(20.0);
    cout << "반지름: " << circle2.getRadius() << endl;
    cout << "넓이: " << circle2.getArea() << endl;
    cout << "둘레: " << circle2.getPerimeter() << endl;
    
    return 0;
}

```
위의 코드에서 Circle이라는 클래스에 radius 변수와 PI 상수가 데이터 멤버로 정의되었고, getRadius, getArea, getPerimeter, setRadius 함수가 멤버 함수로서 정의되었다. 한편, main 함수에서 Circle이라는 클래스(타입)에 대해 circle1이라는 객체(인스턴스)를 생성하였고, 객체.메소드의 형태로 메소드를 호출한 후 매개변수를 전달해 값을 계산하거나 또는 값을 출력하였다.

### 클래스 정의(Class definition)
클래스 정의란 앞에서도 보았듯 사용자 정의 자료형을 새로 정의하는 것이다. 클래스는 헤더(header), 본문(body), 세미콜론(;)으로 구성된다. 클래스의 본문은 중괄호({})로 감싸야 하고, 중괄호 다음 클래스의 마지막에는 세미콜론을 붙여주어야 한다.

데이터 멤버 선언이란 클래스 내에 객체의 데이터를 저장하기 위해 새로운 변수 또는 상수를 선언하는 것이다. 기본 자료형 뿐 아니라 사용자 정의 자료형도 사용 가능하다.

멤버 함수 선언이란, 클래스 내의 멤버 함수를 선언하는 것이다. 일반적으로 멤버 함수는 클래스 내에서는 프로토타입만 선언하고 실제 함수 형태는 클래스 외부에 정의한다. 한편, 외부에서 함수를 실제로 정의할 때에는 구분을 위해 클래스 이름과 스코프 연산자를 함수 이름 앞에 붙여준다.

한편 상수 멤버 함수라는 것도 있다. 상수 멤버 함수란 다른 멤버 함수와 달리 상수(const)로 선언할 수 있는 멤버함수로서, 함수 내에서 데이터 멤버의 값을 바꿀 수 없는 함수를 말한다. 즉 함수 내에서 선언된 지역변수에 대해서는 값 변경을 허용하나, 데이터 멤버에 대해서는 값을 읽고 사용하는 것만 가능하다.

## 어플리케이션
### 객체의 인스턴스화
객체의 인스턴스화는 클래스 데이터 타입으로 객체를 정의함으로서 일반적인 기본 데이터 타입으로 변수/상수를 선언하는 것과 동일한 과정을 거쳐 객체를 인스턴스로 만드는 것을 말한다. 즉 다음의 문장에서 circle1, circle2 객체는 인스턴스화된다.
```cpp
class Circle {
    ...
}

Circle circle1;
Circle circle2;
```

### 멤버 접근 연산자
멤버 접근 연산자란 클래스를 이용해 생성한 객체를 통해 특정 멤버 함수에 접근하고자 할때 사용하는 연산자로, .기호를 사용한다. 해당 멤버 함수를 호출한 객체의 데이터를 매개변수로 전달하는 등의 방식을 통해 멤버 함수를 호출해 사용한다.
```cpp
circle1.setRadius(10.0);
cout << "Radius: " << circle1.getRadius() << endl; 
cout << "Area: " << circle1.getArea() << endl; 
cout << "Perimeter: " << circle1.getPerimeter() << endl << endl;
```
이 코드에서 circle1 객체를 통해 10이라는 값을 setRadius 멤버함수의 매개변수로 호출하며, getRadius, getArea, getPerimeter 멤버함수를 각각 호출한다.

## 접근 제한자(Access modifier)
![화면 캡처 2024-07-09 193010](https://github.com/gkeksd/codding-archive/assets/54362230/47d8a80d-96d1-42ad-b5dd-cb2d305dfaf8)
접근 제한자는 클래스의 각 멤버 요소에 대해 외부로부터의 접근 권한을 설정한다. 이 멤버는 데이터 멤버와 멤버 함수 모두에 대해 해당하며, 기본적인 접근 권한은 private로 설정되어 있다. 이를 따로 설정해줌으로서 접근 권한 변경이 가능하다. 접근 제한자는 크게 private, public, protected로 나뉜다.

### private
private 제한자를 사용하면, **클래스 외부에서 해당 멤버로 직접 접근할 수 없다.** 일반적으로 데이터 멤버는 private로 사용하며, private로 설정된 멤버는 객체 등을 통해서도 직접 접근할 수 없기에 public으로 설정된 멤버를 통해 간접적으로 접근한다. private로 설정하면 다른 사용자가 값을 직접 조작할 수 없게 설정하기에 보안에 유리하다.

### public
public 제한자를 사용하면, **클래스 외부에서 해당 멤버로 직접 접근할 수 있다.** 일반적으로 멤버 함수를 public으로 사용하며, 클래스 외부에서 이 멤버 함수를 직접 호출해 사용할 수 있다.

## 설정자(Setter)/접근자(Getter)
 * 설정자: 설정자는 set함수라고도 부르며, 클래스 외부에서 해당 함수를 통해 private 데이터 멤버의 값을 설정할 수 있게 하기 위해 사용한다.
 * 접근자: 접근자는 get함수라고도 부르며, 클래스 외부에서 해당 함수를 통해 private 데이터 멤버의 값을 얻을 수 있게 하기 위해 사용한다.

설정자와 접근자는 클래스 외부에서 private 멤버의 값을 안전하게 설정하고 사용할 수 있게 하기 위해 사용한다. 이는 객체 지향 언어에서 데이터를 외부로부터 보호하게 하는 것이 필요하기 때문이다.

설정자와 접근자는 다음 코드와 같이 사용한다.
```cpp
#include <iostream>
using namespace std;

class Tmp {
private:
    int _a;
public:
    void setA(int a) {
        if (a > 0)
            _a = a;
    }

    int getA() const {
        return _a;
    }
};

int main() {
    Tmp t;
    t.setA(5);
    cout << t.getA() << endl;
}
```

## 생성자(Constructor)
생성자란 클래스를 통해 객체가 생성되는 과정에서 자동으로 (생성되어) 호출되는 멤버 함수를 말한다. 대부분의 경우 생성자에서는 객체의 값 초기화 및 자원 할당 코드를 작성한다. 생성자의 이름은 클래스 이름과 동일하게 작성하며, 리턴 타입은 없다. 하나의 클래스에서 여러 개의 매개변수 종류를 가진 여러 생성자를 생성할 수 있다.

클래스 내에서 정의되는 생성자는 다음과 같이 짠다.
```cpp
class Circle
{
 ...
public:
 Circle(); // default constructor
 Circle(int id, double radius); // parameter constructor
 Circle(const Circle& circle); // copy constructor
 Circle(double radius); // conversion constructor
 Circle(Circle&& circle); // move constructor
 ...
}
```
main 함수에서 객체를 통해 생성자를 호출할 때는, 컴파일러가 생성자를 호출할 때 사용한 매개변수 종류 및 순서에 맞는 생성자를 자동으로 호출한다.

생성자의 종류로는 기본 생성자, 매개변수 생성자, 복사 생성자, 변환 생성자, 이동 생성자가 있다. 이중 앞의 세 개만 살펴보자.

### 기본 생성자
기본 생성자는 위의 코드에서 괄호 안에 아무것도 들지 않은 생성자로, 객체를 생성할 때 값을 지정하지 않고 생성하거나 중괄호({})만 사용하면 기본 생성자가 호출된다. 한편 기본 생성자는 **일반적인 경우 직접 쓰지 않아도 객체를 생성할 때 기본 생성자 양식에 맞게 생성하면 컴파일러가 자동으로 추가해 준다.**

물론 기본 생성자에서 멤버 함수의 본문에 해당하는 부분은 프로그래머가 원하는 대로 채울 수 있다.

### 매개변수 생성자
매개변수 생성자는 위의 코드에서 두번째 생성자에 해당하며, 생성자 선언 및 객체 생성 시에 특정 데이터 타입을 가진 매개변수를 전달할 때 매개변수 생성자라 한다. 이때 객체에서 전달하는 매개변수의 타입과 순서는 생성자에서 정의한 매개변수 타입과 순서에 일치해야 한다.

### 복사 생성자
복사 생성자는 위의 코드에서 세번째 생성자에 해당하며, 생성자 선언 및 객체 생성 시에 다른 객체를 매개변수로 전달함으로서 해당 객체의 값을 복사하는 생성자이다. 복사 생성자를 선언할 때는 const 클래스& 변수명 형식으로 선언하는데, 이 중 const는 Rvalue 값을 복사할 때를 대비해 사용하며, &는 객체 복사 시에는 pass by value 방식이 허용되지 않고 오직 pass by reference 방식으로만 복사해야 하기 때문이다. 

pass by value가 허용되지 않는 이유는, pass by value로 값을 복사할 때 매개변수를 새로 생성하여 그 안에 값을 복사하는데, 이 복사하는 과정에서 매개변수를 새로 생성되는 등 매개변수 생성->복사 과정이 계속 반복되어 무한루프에 빠지기 때문이다. 

한편 복사 생성자를 쓰지 않아도 객체에서 복사 생성자를 호출하면 컴파일러가 자동적으로 빈 내용을 가진 복사 생성자를 생성해 호출하지만, 이는 얕은 복사 방식으로서 깊은 복사 방식을 사용하도록 생성자를 직접 선언하는 것이 낫다(이에 대해서는 포인터 챕터에서)

### 멤버 초기화 리스트(Member initialize list)
멤버 초기화 리스트란 생성자 정의 시에 생성자 이름과 중괄호 사이에서 데이터 멤버를 생성자의 매개변수로 초기화하는 과정으로, 다음과 같이 사용한다.
```cpp
class Student {
private:
    int _id;
    string _name;
public:
    Student(int id, string name) : _id{id}, _name{name} {
        ...
    }
}
```
다음과 같이 초기화할 데이터 멤버{값을 할당할 매개변수} 형식으로 초기화할 수 있다. 이때 매개변수의 이름과 데이터 멤버의 이름이 같아도 지장이 없지만, 구분을 위해 다르게 하는 것이 바람직하다.

### 소멸자(Destructor)
소멸자란 코드가 끝나 객체가 소멸되는 과정에서 자동으로 (생성되어) 호출되는 멤버 함수이다. 생성자는 클래스 이름 앞에 ~를 붙여 선언하며, 보통 본문에는 객체가 점유 중이던 자원을 반환하거나 이를 이용해 특정한 문장을 출력하는 식의 내용을 넣는다. 생성자와 마찬가지로 리턴 타입은 없고, 생성자와는 달리 매개변수도 없다.

프로그래머가 명시적으로 소멸자를 정의하지 않으면 컴파일러가 자동으로 빈 소멸자를 정의하여 호출한다. 소멸자는 한 클래스 당 하나만 사용할 수 있다.
```cpp
class Circle {
    ...
public:
    ...
    ~Circle();
}
```

### 합성 멤버함수(Synthetic member function)
생성자를 선언할 때 차후 내용을 정의하는 대신, 특정 키워드를 사용해 이를 대체하는 것을 말한다. default 키워드를 사용해 생성자가 기본 내용을 사용하도록, delete 키워드를 사용해 생성자가 기능을 삭제하여 사용하지 않도록 할 수 있다. 보통 다음과 같이 사용한다.
```cpp
class Student {
    ...
public:
    Student() = default; //기본 내용 사용
    ~Student() = delete; //사용x. // 소멸자를 사용하지 않으면 오류 발생
}
```

## 예제
다음 예제는 각각 매개변수 생성자, 복사 생성자, 기본 생성자를 호출하고 각각 원의 반지름, 넓이, 둘레를 계산한다.
```cpp
#include <iostream>
using namespace std;

class Circle {
private:
    double radius;
    const double PI = 3.14;

public:
    Circle();
    Circle(double radius);
    Circle(const Circle& circle);
    ~Circle();
    void setRadius(double radius);
    double getRadius() const;
    double getArea() const;
    double getPerimeter() const;
};

Circle::Circle() : radius(0.0) {
    cout << "기본 생성자가 호출되었습니다." << endl;
}

Circle::Circle(double rds) : radius(rds) {
    cout << "매개변수가 생성자가 호출되었습니다." << endl;
}

Circle::Circle(const Circle& circle) : radius(circle.radius) {
    cout << "복사 생성자가 호출되었습니다." << endl;
}

Circle::~Circle() {
    cout << "소멸자가 호출되었습니다. 반지름: " << radius << endl;
}

void Circle::setRadius(double value) {
    radius = value;
}

double Circle::getRadius() const {
    return radius;
}

double Circle::getArea() const {
    return PI * radius * radius;
}

double Circle::getPerimeter() const {
    return 2 * PI * radius;
}

int main() {
    Circle circle1(5.2); //매개변수 생성자
    cout << "반지름: " << circle1.getRadius() << endl;
    cout << "넓이: " << circle1.getArea() << endl;
    cout << "둘레: " << circle1.getPerimeter() << endl;

    Circle circle2(circle1); //복사 생성자
    cout << "반지름: " << circle2.getRadius() << endl;
    cout << "넓이: " << circle2.getArea() << endl;
    cout << "둘레: " << circle2.getPerimeter() << endl;

    Circle circle3; //기본 생성자
    cout << "반지름: " << circle3.getRadius() << endl;
    cout << "넓이: " << circle3.getArea() << endl;
    cout << "둘레: " << circle3.getPerimeter() << endl;

    return 0;
}
```
