## 프로그래밍 기본
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!" << endl;

    return 0;
}
```
### 프로그램 분석
 * #include <iostram>: iostream 헤더 파일을 가져오겠다는 선언
 * using namespace std: cout, cin 등의 함수가 담긴 std라는 namespace를 자동으로 선언하고, 함수 앞에 std::를 생략해도 되게 하겠다는 뜻
 * cout: console out의 줄임말로, <<라는 명령어를 통해 출력을 수행하는 함수
 * endl: end line의 줄임말로, 한 줄을 끝내고 다음 줄로 넘어가는 것을 뜻하는 함수
 * return 0: 프로그램을 종료할 시 사용하는 코드로, 특정 값을 반환하도록 한다. 일반적인 경우 0을 반환하지만 0 이외의 특수한 값을 반환하는 경우도 있음. 0을 반환할 시 코드를 생략해도 컴파일러가 알아서 채워줌

### 프로그래밍의 원칙
1. 대소문자 구분: C++ 등 많은 언어는 대소문자를 다른 문자로 구분하기에 이를 정확히 구분하는 것이 필요. 
2. 들여쓰기: C++의 경우 들여쓰기를 지키지 않아도 오류가 나지는 않으나, 가독성의 이유로 들여쓰기를 지키는 것이 추천됨. 파이썬 등 일부 중괄호를 쓰지 않는 언어의 경우 들여쓰기를 지키지 않으면 문법이 에러가 남.

 * 여러 줄 주석: 여러 줄짜리 긴 내용을 입력해 주석을 만들때 사용. /* 내용 */식으로 사용됨.

### namespace
```cpp
namespace myNamespace = {
   void name1() = {
       cout << "name1" << endl;
   }
   void name2() = {
       cout << "name2" << endl;
   }
}

using namespace::name2
```
 * 변수나 함수 등의 이름(내부 식별자)이 동일하게 설계되어 충돌이 일어나는 것을 방지하기 위해 사용되는 것.
 * namespace를 새로 생성할 시 main 함수 외부에서 전역 namespace를 생성해야 함.
 * using namespace::name2는 name2 함수 부분에만 namespace 이름을 붙이는 것을 생략하게 하겠다는 것.

## 자료형
자료형은 크게 정수, 실수, 문자열 등의 기본 자료형(built-in data type)과 배열, 함수, 포인터 등의 파생 자료형(derived data type), 구조체, 공용체, 클래스 등의 사용자 정의 자료형(user-defines data type) 등으로 나뉨

### 정수 자료형(integer type)
int라고 쓰며, 정수만을 제공하는 가장 기본적인 자료형이다. 정수 자료형 내에서도 정수의 범위와 비트의 종류에 따라 여러가지로 나뉜다. 한편 부호가 존재하는 signed int와 부호가 존재하지 않는 unsigned int로 나뉘며, 둘은 표현할 수 있는 정수 범위가 살짝 다르다.

한편 정수를 2진수로 변환할 때 7부터 -8까지는 2의 보수법을 사용해 변환한다.

 * char: 1바이트 8비트 자료형으로, -128~127(unsigned의 경우 0~255)까지의 숫자를 다룸. 문자열을 표현할 때에도 사용(아스키 코드)
 * short int: 2바이트 16비트 자료형으로, -32,768~32,767(unsigned의 경우 0~65,535)의 범위를 다룸. int를 생략하고 사용도 가능.
 * int: 4바이트 32비트 자료형, 대략 -21억부터 +21억(unsigned의 경우 0부터 약 43억까지)까지의 범위를 다룸. 가장 기본적으로 사용됨.
 * long int: 4바이트 32비트 자료형. 범위는 int와 동일함. int 생략 가능.
 * long long int: 8바이트 64비트 자료형. 범위는 매우 넓음.  int 생략 가능.

### 캐릭터 자료형(character type)
char라고 쓰며, 기본적으로는 정수 자료형의 일종이나 보통 한 글자의 문자열을 표현하는 데에도 많이 사용됨. 정식으로 문자열을 표기하는 것이 아니기에 아스키 코드에 등록된 문자만을 정수 형태로 변환해 저장함. 값을 참조하는 방법에 따라 char *, char[]도 존재.

```cpp
char str1 = 'A'; 
char str2 = str1 + 2; // C
char str3 = str2 - 1; // B
char str4 = str1 + 3; // D
```
문자를 정수 형태로 저장하기에 정수 연산을 통해 새로운 문자를 저장, 출력하는 것이 가능함.

#### 이스케이프 시퀀스
문장을 출력할 때 중간에 삽입해 특수한 기능을 수행하는 문자로 백슬래쉬(\\)를 사용
 * \n: 다음 줄로 이동(최근에는 자동으로 다음 줄 첫번째로 커서가 이동)
 * \t: 탭 키만큼 이동
 * \r: 캐리지 리턴. 커서를 그 줄의 맨 처음으로 이동. 그 줄에서 \r을 수행 시 이미 입력되어 있던 문장은 새로 입력되는 문장에 덮어씌워짐.
 * \\ \\(백슬래쉬 두번): 백슬래쉬를 문장 안에 입력할 때 사용
 * \\": 문장 안에 곁따옴표(")를 입력할 때 사용
 * \\': 문장 안에 홑따옴표(')를 입력할 때 사용
키보드의 엔터(enter)키의 모양은 과거 타자기 및 초창기 컴퓨터에서 다음 줄로 이동하기 위해 \n+\r을 입력해야 했던 시절의 잔재

### 불 자료형(bool data type)
참/거짓을 판단하는 자료형으로, bool로 선언. 0이 아닌 정수는 true로, 0은 false로 판정하며 문자열 true나 false일 경우에도 마찬가지. true 판정일 경우 1로, false 판정일 경우 0을 반환한다.

예: bool x = 123;일 경우 x는 출력 시 true 판정되어 1로 출력됨

### 실수 자료형(floating data type)
정수로 떨어지지 않는 모든 종류의 실수를 표현하는 자료형. float와 double의 두 가지로 나뉨. double이 float보다 소수점 이하 더 많은 자릿수를 정확히 표기 가능함.

### 문자열 자료형(string data type)
한 자리 이상의 문자로 이루어진 문자열을 표현하는 자료형. string을 사용한다. 사용을 위해서 string 헤더 파일을 읽어들어야 하며, std 네임스페이스에 속해 있기에 using 문 비사용 시 std::를 붙여야 한다.
